# Recall Digest

View the latest weekly digest report showing lesson precision trends.

## Usage

- `/recall digest` — show the latest weekly digest
- `/recall digest --generate` — generate a fresh digest for the current week

## What It Contains

- Session count and overall precision
- Top performing lessons (high citation rate)
- Noise offenders (low precision)

Reports saved to `~/.local/state/claude-recall/reports/`.
